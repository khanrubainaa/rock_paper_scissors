
# Rock Paper Scissors

A command-line Rock Paper Scissors game built using Python.

## Features
- User chooses Rock, Paper, or Scissors.
- Computer makes a random choice.
- Plays 5 rounds.
- Displays the winner of each round.
- Keeps track of user and computer scores.
- Displays the final winner.
- Handles invalid user inputs.

## Concepts Used
- Random module
- Functions
- For loop
- If-Elif-Else
- User input
- Variables and operators
- F-strings

## How to Run

python rock_paper_scissors.py
